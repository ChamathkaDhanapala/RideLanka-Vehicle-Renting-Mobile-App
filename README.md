# 🏍️ RideLanka - Vehicle Renting Mobile App

Ride Lanka is a mobile application built with **React Native (Expo)** designed to connect tourists visiting Sri Lanka with local vehicle owners for convenient vehicle rentals. This platform serves as a marketplace where tourists can browse, filter, and select vehicles, then directly contact owners to complete rentals.

## ✨ Features  

- **Browse Vehicles** - Explore by category (Cars, Bikes, Tuk-Tuks, Vans, etc.)
- **Smart Filtering** - Filter by price, location, and vehicle type  
- **Detailed Listings** - View price, features, location, and images  
- **Owner Contact** - Direct contact with vehicle owners
- **Location Services** - View pickup locations with maps integration
- **User Profiles** - Personal profiles with rental history
- **Clean UI/UX** - Modern design based on Figma prototypes

## 🛠️ Tech Stack  

- **Frontend**: React Native (Expo)
- **Navigation**: React Navigation
- **Design**: Figma
- **Images**: Unsplash API
- **Icons**: Expo Vector Icons

## 📱 Screens

- **Onboarding** - Welcome screen with app introduction
- **Splash** - Beautiful loading screen
- **Home** - Featured vehicles and categories
- **Explore** - Browse all vehicles with filters
- **Favorites** - Saved vehicles list
- **Profile** - User information and settings
- **Vehicle Details** - Comprehensive vehicle information
- **Contact** - Owner contact and location details
- **Notifications** - Alerts and updates

## 🚀 Installation & Setup

### Prerequisites
- Node.js (version 14 or higher)
- Expo CLI (`npm install -g expo-cli`)
- Android Studio / Xcode (for emulators) or Expo Go app

### Steps to Run

1. **Clone the repository**
   
```bash
git clone https://github.com/ChamathkaDhanapala/RideLanka-Vehicle-Renting-Mobile-App.git
cd RideLanka-Vehicle-Renting-Mobile-App
```
2. **Install dependencies**
   
```bash
npm install
```
3. **Start the development server**
```bash
npx expo start
```
4. **Start the development server**
- Scan QR code with Expo Go app (Android/iOS)
- Or press 'a' for Android emulator / 'i' for iOS simulator
